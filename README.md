# How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect the dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?
I write programs that are maintainable and readable by giving each function a clear purpose and not wasting space. This makes any part of my code reusable and alterable so that they can be changed without affecting the project at large, and thus adaptable. For example, I created four functions for the CRUD Python Module, create, update, read, and delete. These are all functions that do not call upon one another and thus can be updated and changed if needed. This allowed me to alter the database using the python code and connect them to the dashboard for Project two without being changed in any way.

I approach these problems by breaking them into small and manageable parts to find out what each parts needs to work to accomplish my goals. I did this when creating my dashboard by first connecting to the database, then creating an HTML header and signifier, then creating the dashboard widgets separately.
